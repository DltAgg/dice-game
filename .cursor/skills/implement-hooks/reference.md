# Hook catalogue

Read `StandingTrigger` in `src/server/model/cards.ts` before adding a member.
Current events include `on-attack` and `on-take-damage`. One event, one hook,
filters on the ability.

Proving cards are Response or Modify, or a Fighter ability. Print follows
[`docs/KEYWORDS.md`](../../../docs/KEYWORDS.md). Do not use a ritual, an
overload, or a pile absorb as the proving host. Do not cite a deleted spec.
