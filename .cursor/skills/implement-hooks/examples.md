# Hook examples

One shared event, filters on the ability, effects as data. Proving-card print
comes from [`docs/KEYWORDS.md`](../../../docs/KEYWORDS.md).

A Fighter standing ability and an attached moveset use `StandingTrigger`.
Do not add a ritual host or a pile-bank absorb example. `[Block N]` on take
damage is `reduceBy`. It lowers damage. It does not cancel the hit.

If the clause is not modelled, leave the ability empty and add a row to
`docs/DEFERRED_CATALOGUE.md`.
